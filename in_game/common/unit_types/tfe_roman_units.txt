# TFE: the Roman empires field the late army's two grades of foot (Notitia Dignitatum): the Comitatenses of the field
# armies and the Limitanei who held the frontier forts. They are vanilla's Footmen and Archers under Roman names and
# pictures. A unit type cannot be renamed for one country, so they are new types, as vanilla's own legionaries are.
# Rome cannot recruit Footmen or Archers, so its recruit list shows only these. The Stilicho opening's legions are
# created by category, so they come out as Comitatenses too.
# Pictures: a unit's own gfx tags are tried before its soldiers' culture, so a tag named after an illustration
# (illustrations/units/army_infantry_<tag>.dds) shows it in both empires whatever the regiment's culture. The
# Comitatenses' armoured spearmen are Fate of the Phoenix's, not copied; without it they fall back to the generic
# infantry. The Limitanei have their own picture, main_menu/gfx/interface/illustrations/units/army_infantry_tfe_limitanei.dds
# (and masks/), which the game tries before any tag: the helmeted spearman cropped from the base game's middle_east_gfx.

tfe_comitatenses = {
	copy_from = a_footmen
	country_potential = { OR = { tfe_is_western_rome = yes has_or_had_tag = EAR } }	# a copy keeps vanilla's, which bars Rome
	gfx_tags = { medium_tag east_mediterranean_gfx }	# armoured spearmen behind big shields: the field army's line
}

tfe_limitanei = {
	copy_from = a_archers
	country_potential = { OR = { tfe_is_western_rome = yes has_or_had_tag = EAR } }
	gfx_tags = { medium_tag }	# vanilla Archers' 3D look minus the bows; the picture is its own file
}
