# Stilicho's Glory Implementation Plan (RoadMap #27)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Glory bar for Stilicho in the Decline of the West panel that moves on named causes, sets the West's
morale, and at its height brings a showdown with Honorius: stand with Stilicho (he revolts, the player follows him and
can win the West by taking Honorius's capital) or with the Emperor (Stilicho dies and the West begins to collapse).

**Architecture:** New script is typed Python in `script/` (`defs_stilicho.py` for triggers, effects, on_actions and
auto-modifiers; `stilicho_events.py` for the events and their text; `defs_western_rome.py` and `defs_usurpers.py` for
shared pieces). Glory lives on the Decline of the West situation (`var:tfe_stilicho_glory`), so it follows Stilicho
from WRE to his own country and the panel can read it. Its tiers are auto-modifiers keyed on "Stilicho serves this
country". The revolt reuses Gildo's proven shape (`create_rebel`, pops' allegiance, `start_revolt`, crowning a day
later), and the win is an `on_location_occupied`/`on_siege_won` hook on Honorius's capital.

**Tech Stack:** EU5 script generated by `tools/pdx` (Python, checked by `pyright`), hand-written `.txt`/`.gui`/`.yml`
where a file is not generated, pytest under `tools/`, the game itself driven by `tools/eu5ctl.sh`.

**Spec:** `docs/specs/2026-09-30-stilichos-glory-design.md` (read it first; this plan argues from it).

## Design decisions the spec left open (settled here)

| Spec says | This plan does | Why |
|---|---|---|
| Stilicho's West "takes the WRE tag if the game allows" | It keeps its own tag `STILI` and takes WRE's name, adjective and flag | `effects.log` has no tag-change effect (only `define_unique_country_tag`, for new countries) |
| `extend_regency = { years = 8 }` | `extend_regency = 8` | The effect takes a bare number of years (vanilla `regency_events.txt:323`) |
| Glory is `var:tfe_stilicho_glory` on WRE | It lives on `situation:tfe_decline_of_the_west` | It has to follow Stilicho to `STILI`, and the panel already reads situation variables |
| `tfe_stilicho_regency` stretched to 408 | It becomes an auto-modifier, "Stilicho's Command", active while Stilicho serves the country | It lasts to 408, moves with him when he rises and ends when he dies, with no bookkeeping |
| Battles scaled by battle size | +2 won, -3 lost; a great battle adds +3 won, -3 lost more | No trigger reads a battle's size. The saved `killed_land_units` is not proven, so vanilla's own "great battle" is the size signal |
| Core land lost: -2 per province | -1 per core location taken from us in a peace treaty | The hook fires per location. A province is 3–8 locations, and one event cannot count a whole province |
| Showdown "when the regency ends in 408" | Fires on 22 Aug 408, Stilicho's historical fall, 4961 days after the start. The regency itself ends on 9 Sep 408 | A dated event is simpler than hooking `on_regency_end`, which is empty in vanilla and overwritten by the game |
| Olympius, "poor ruling skills" | He is created at the showdown: adm 30, dip 35, mil 5 | He is not in the 395 setup |
| "Stand with Stilicho" shown with a ✓/✗ tick | The option's `trigger` is a `custom_tooltip` block | EU5's `show_as_unavailable` is marked NOT IMPLEMENTED in `events/readme.txt`. The in-game check decides whether a failed option shows greyed out or is hidden |

## Review Focus

1. **Stilicho dies inside the machinery.** Stilicho can die mid-revolt (in battle, or of age), or between the
   showdown's immediate and its option. The expected result: no second showdown, no collapse for WRE while he is
   STILI's ruler, the Glory bar closes, and Eucherius inherits STILI. Tested in Task 5 (the death hook's
   `tfe_western_rome` branch) and Task 8 step 4.
2. **Our own land transfers must not count as losses.** The revolt, Britain and Africa breaking away, and Gildo's rising
   all move land by effect, not by peace treaty. Glory must not drop for them. Tested in Task 4: a test asserts the
   core-land hook is `on_took_location_in_peace_treaty` and skips migrators and usurpers.
3. **The win runs while Honorius is dead or already gone.** The annex must still happen, and only the "Rome is ours"
   option shows. Tested in Task 7: a test asserts options a and b require Honorius alive and option c requires him dead.
4. **Honorius's capital is not Ravenna.** The win hook compares against `c:WRE.capital`, not a fixed location, and
   covers fortified capitals (`on_siege_won`) as well as unfortified ones (`on_location_occupied`). Tested in Task 7.
5. **After a win, `WRE` no longer exists.** The Decline of the West must not end, the barbarians must still have a
   West to march on, and the panel must not spam `gui.log`. Tested in Task 1 (`can_end` uses `tfe_is_western_rome`)
   and in Task 8 step 5 (in game: open the panel after a win and check `gui.log`).

Shared test helper, pasted at the top of both new test files:

```python
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT / "tools"))
sys.path.insert(0, str(ROOT / "script"))


def flat(rel):
    """a script file without comments, whitespace collapsed: `a = {\n\tb = c\n}` reads `a = { b = c }`."""
    return " ".join(re.sub(r"#[^\n]*", "", (ROOT / rel).read_text(encoding="utf-8-sig")).split())


def block(text, head):
    """the `{ ... }` body that follows `head` in flattened text (brace-matched)."""
    i = text.index(head) + len(head)
    i = text.index("{", i)
    depth = 0
    for j in range(i, len(text)):
        depth += {"{": 1, "}": -1}.get(text[j], 0)
        if depth == 0:
            return text[i + 1:j]
    raise ValueError(head)
```

"""Stilicho's Glory (RoadMap #27): the confidence Rome has in one man. Triggers, effects, on_actions and the Glory
tiers. Glory is a variable on the Decline of the West's situation, so it follows Stilicho if he rises."""
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent / "tools"))
from pdx.api import AnyFx, CharacterTrig, CountryFx, CountryTrig, LocationTrig, SituationFx, SituationTrig
from pdx.objects import Doc
from pdx.objects_defs import Defs

DECLINE = "tfe_decline_of_the_west"
GLORY = "tfe_stilicho_glory"
SHOWDOWN_DAYS = 4961   # 395.1.18 + 4961 days (365-day years) = 22 August 408, the day Stilicho fell

# (name, from, below, modifiers): the tiers of Glory. Morale nets against Debased Currency (-15%) and his command (+10%).
TIERS = (
    ("tfe_glory_discredited", None, 25, {"land_morale_modifier": -0.1, "monthly_legitimacy": -0.1,
                                         "global_estate_target_satisfaction": -0.05}),
    ("tfe_glory_wanes", 25, 50, {"land_morale_modifier": -0.05, "monthly_legitimacy": -0.05}),
    ("tfe_glory_rises", 75, 90, {"land_morale_modifier": 0.1, "global_manpower_modifier": 0.1}),
    ("tfe_glory_idol", 90, None, {"land_morale_modifier": 0.2, "global_manpower_modifier": 0.15}),
)


def glory_at_least(t, n, op=">="):
    """`situation:tfe_decline_of_the_west ?= { var:tfe_stilicho_glory >= n }` inside a trigger."""
    with t.go_situation(DECLINE, op="?=") as s:
        s.has_variable(GLORY)
        s.var(GLORY, op, n)


def glory_between(t, lo, hi):
    """a tier's potential: Stilicho serves this country and Glory is in [lo, hi) (None = open)."""
    t.tfe_stilicho_serves_us()
    with t.go_situation(DECLINE, op="?=") as s:
        s.has_variable(GLORY)
        if lo is not None:
            s.var(GLORY, ">=", lo)
        if hi is not None:
            s.var(GLORY, "<", hi)


def triggers():
    d = Defs()
    d.note("TFE: Stilicho's Glory. Scope: a country. Stilicho is alive and in its service: the regent of Honorius's West, or\n"
           "the ruler of his own once he rises. `prev`, not root: root is whoever asked.")
    with d.trigger("tfe_stilicho_serves_us", CountryTrig) as t:
        with t.link("character:tfe_stilicho", CharacterTrig, op="?=") as s:
            s.is_alive(True)
            s.compare("employer", "?=", "prev")
    return d


def effects():
    d = Defs()
    d.note("Scope: a country. Glory moves by $amount$ if Stilicho serves this country and the bar is open (it closes when he\n"
           "falls). Kept 0-100. The first time it reaches 80 Olympius starts whispering (tfe_stilicho.1); at 100 the showdown\n"
           "comes (tfe_stilicho.2).")
    with d.effect("tfe_add_stilicho_glory", CountryFx) as e, e.if_() as i:
        with i.limit() as t:
            t.tfe_stilicho_serves_us()
            with t.go_situation(DECLINE, op="?=") as s:
                s.has_variable(GLORY)
        with i.go_situation(DECLINE) as s:
            s.change_variable(name=GLORY, add="$amount$")
            s.clamp_variable(name=GLORY, min=0, max=100)
        with i.if_() as w:
            with w.limit() as t:
                with t.not_() as n:
                    n.has_global_variable("tfe_stilicho_warned")
                glory_at_least(t, 80)
            w.set_global_variable("tfe_stilicho_warned")
            w.trigger_event_non_silently("tfe_stilicho.1")
        with i.if_() as w:
            with w.limit() as t:
                with t.not_() as n:
                    n.has_global_variable("tfe_stilicho_showdown")
                glory_at_least(t, 100)
            w.trigger_event_non_silently("tfe_stilicho.2")
    return d


def on_actions():
    d = Defs()
    d.note("TFE: Stilicho's Glory. On day one his regency is stretched to 408 (the setup ends it at Honorius's majority,\n"
           "9 Sep 400), and the showdown is set for 22 Aug 408 in case Glory never forces it sooner.")
    d.hook("on_game_start", "tfe_on_start_stilicho")
    with d.on_action("tfe_on_start_stilicho") as a, a.effect(AnyFx) as e:
        with e.link("c:WRE", CountryFx, op="?=") as w:
            w.extend_regency(8)
            w.trigger_event_non_silently(id="tfe_stilicho.2", days=SHOWDOWN_DAYS)
    return d


def auto_modifiers():
    doc = Doc()
    doc.note("TFE: Stilicho's Glory. Each applies while Stilicho serves the country, so all of them move with him if he rises.")
    doc.note("his command: the army is his and the great houses follow him (was the 68-month tfe_stilicho_regency)")
    doc.modifier("tfe_stilicho_regency", potential=lambda t: t.tfe_stilicho_serves_us(),
                 land_morale_modifier=0.1, global_nobles_estate_power=0.2)
    for name, lo, hi, mods in TIERS:
        doc.modifier(name, potential=lambda t, lo=lo, hi=hi: glory_between(t, lo, hi), **mods)
    return doc


def biases():
    doc = Doc()
    doc.note("TFE: what the East thinks of how the West settles Stilicho (events/tfe_stilicho.txt)")
    return doc


def outputs():
    """{repo-relative path: text}; write each with encoding="utf-8-sig" (the BOM is the writer's job)."""
    return {"in_game/common/scripted_triggers/tfe_stilicho.txt": triggers().text(),
            "in_game/common/scripted_effects/tfe_stilicho.txt": effects().text(),
            "in_game/common/on_action/tfe_stilicho.txt": on_actions().text(),
            "in_game/common/auto_modifiers/tfe_stilicho.txt": auto_modifiers().text(),
            "in_game/common/biases/tfe_stilicho.txt": biases().text()}
