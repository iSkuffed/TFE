# 395 Cultures Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]` syntax.

**Goal:** Replace the 1337 culture map of the TFE core with a 395 one (hybrid: vanilla remaps + 12 new cultures).

**Architecture:** New culture definitions in `in_game/common/cultures/tfe_cultures.txt`; a first-match rule table
`tools/cultures.txt` applied by `tools/borders.py` to every pop of the generated `06_pops.txt`; tags, characters
and the empires' accepted cultures follow.

**Tech Stack:** Python 3 (uv, pytest), EU5 1.3.11 script, `tools/eu5ctl.sh` for in-game checks.

**Spec:** `docs/specs/2026-09-26-395-cultures-design.md`

## Global Constraints

- Script and localization files: UTF-8 with BOM; generated `setup/start` files: no BOM (start crash otherwise).
- Suite: `uv run --with pytest --with numpy --with pillow --with shapely pytest tools -q`.
- Regenerate: `uv run --with numpy --with pillow --with shapely python3 tools/borders.py` (grep its output for
  ERROR / Traceback; never silence it).
- Commits end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`; work on master.
- Never touch the EU5 crash reporter; never kill the user's own Steam-launched EU5.

## Review Focus

1. A 1337 culture spread across two 395 zones (Arabic in Levant vs Maghreb) must be split by scope, not culture.
2. Pops on land owned by no one (`none`) must still get a 395 culture.
3. Society-of-Pops tribal pops (tag culture from tags.txt) must end on the tag's new culture.
4. roman_culture ships `active = no`: Roman pops must actually appear and count as active.
5. Accepted cultures must not be dropped by the `include = template` line (template may set its own).
